## 当前生成口径

`scripts/build_data.py` 以静态报告整理数据作为种子，并优先用 `data/data_xlsx_format` 下的 Excel/XLS 源文件覆盖可结构化抽取的字段：

- `区域内投入产出表及计算/*.xlsx`：生成 2017、2023 年北京、天津、河北主导产业。
- `京津冀重点产业链区域分布/*.xls`：生成六条重点产业链上中下游实缴资本及合计。
- `企业问卷调查/*.xlsx`：生成企业创新合作障碍和区域协同问题统计。
- `区域间投入产出表构建及计算/*.xlsx`：核验区域产业联动分析使用的表3-3口径来源工作簿、计算页和 42 部门映射标签。

`scripts/validate_data.py` 会重新抽取或核验上述源工作簿，并逐项校验 `data/report_data.json` 中的 `leadingIndustries`、`chainCapital`、`survey` 与区域产业联动来源元数据保持一致。

## 修订痕迹处理

研究报告存在 Word 修订痕迹。对于源工作簿未提供完整结构化表的报告叙述和政策聚合，本项目仍保留底层 OOXML 整理口径。

OOXML 整理时采用：

```text
包含 w:t 与 w:ins 中的当前可见文本；
排除 w:delText 删除修订；
不接受、不拒绝原文之外的任何数值变更；
原表中的错字、疑似不一致总计、空格均按报告原貌保留。
```

## 地图边界数据

区域总产出画像页使用省级真实边界 GeoJSON，来源为 DataV 地理边界服务：

```text
https://geo.datav.aliyun.com/areas_v3/bound/110000.json
https://geo.datav.aliyun.com/areas_v3/bound/120000.json
https://geo.datav.aliyun.com/areas_v3/bound/130000.json
```

项目内合并文件为 `data/geo/jingjinji_boundaries.json`。前端只读取该本地文件；若文件不可访问，区域总产出画像会退回内置示意轮廓，避免页面空白。

区域产业联动分析页使用 `data/data_xlsx_format/区域间投入产出表构建及计算` 下的 2017、2022 年京津冀投入产出源工作簿作为表3-3口径来源。构建与校验脚本检查 `乘数效应`、`溢出效应`、`乘数效应占比`、`北京溢出效应`、`天津溢出效应`、`河北溢出效应` 等计算页，并核验六链上中下游 42 部门映射标签存在。

## 未使用或未伪造的数据

开发文档建议准备 `policy_detail.csv`、`policy_panel.csv` 等表，但研究报告只给出了政策文本量化后的聚合结果，没有提供 101 条政策逐条明细。因此当前项目不生成逐条政策数据，避免凭空补数。

报告中的企业空间分布图来自图片与正文描述，未形成完整可抽取的市区级结构化表。本项目没有把图片中的点位反向识别成数据，只使用报告正文和表格中明确列出的数值。

## 源表差异说明

切换到 `data_xlsx_format` 源工作簿后，少量数值与此前从报告转录的 JSON 不完全一致：

- `网络安全和工业互联网` 六链资本以 `京津冀重点产业链区域分布` 下对应 `.xls` 文件底部汇总值为准。
- 企业问卷中 `氢能` 的 `市场方面的信息不对称` 统计为 7，来自问卷源表对应选项计数。
- 六链资本的地区合计和三地合计按生成后的阶段值加总，避免前端展示时出现阶段值与合计值不一致。

## 派生指标

界面中少量指标为由报告原表直接计算得出，并在页面中标注：

- 总量增幅：由表1-4总产出 `407225.50 / 225961.62 - 1` 计算。
- 六链资本合计：按表2系列六条产业链的“地区合计”加总。
- 柱状图排序、最大值缩放、色阶强度：仅用于视觉呈现，不改变原始数值。
