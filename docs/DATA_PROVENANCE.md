## 修订痕迹处理

研究报告存在 Word 修订痕迹。直接用 `python-docx` 读取时，会漏掉位于插入修订 `w:ins` 中的一部分表格数字，例如新能源和智能网联汽车资本表会被读成空表。

因此本项目使用底层 OOXML 口径整理数据：

```text
包含 w:t 与 w:ins 中的当前可见文本；
排除 w:delText 删除修订；
不接受、不拒绝原文之外的任何数值变更；
原表中的错字、疑似不一致总计、空格均按报告原貌保留。
```

## 未使用或未伪造的数据

开发文档建议准备 `policy_detail.csv`、`policy_panel.csv` 等表，但研究报告只给出了政策文本量化后的聚合结果，没有提供 101 条政策逐条明细。因此当前项目不生成逐条政策数据，避免凭空补数。

报告中的企业空间分布图来自图片与正文描述，未形成完整可抽取的市区级结构化表。本项目没有把图片中的点位反向识别成数据，只使用报告正文和表格中明确列出的数值。

## 派生指标

界面中少量指标为由报告原表直接计算得出，并在页面中标注：

- 六链资本合计：按表2系列六条产业链的“地区合计”加总。
- 柱状图排序、最大值缩放、色阶强度：仅用于视觉呈现，不改变原始数值。
