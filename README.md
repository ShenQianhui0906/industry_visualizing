# 京津冀产业与政策时空演化分析平台

基于研究报告《基于投入产出的京津冀产业链关联度测度与提升路径研究》实现的 DataV 风格可交互成果展示界面。

本项目按开发文档中的页面结构组织：`首页总览`、`区域画像`、`时空演化`、`政策产业联动`、`产业专题`、`数据与方法`。当前环境没有安装 `streamlit` 与 `plotly`，因此实现为无 Node、无联网依赖的静态 Web 项目，使用 Python 标准库启动本地预览服务。

## 快速运行

```bash
python3 scripts/build_data.py
python3 scripts/validate_data.py
python3 scripts/preview.py
```

打开：

```text
http://127.0.0.1:8765
```

## 数据原则

所有数值均来自研究报告当前可见版本，抽取时采用：

```text
包含 w:ins 插入修订，排除 w:delText 删除修订；原表错字、空格与报告口径不重算、不改写。
```

项目没有伪造 `policy_detail.csv` 这类逐条政策明细，因为报告只提供了 101 份政策文本的聚合量化结果，没有给出 101 条政策的逐条记录。

## 已实现页面

- 首页总览：区域总产出、政策文本、企业调研、区域网络、六链资本结构、核心发现。
- 区域画像：按北京、天津、河北切换，展示总产出、静态乘数、动态推动、六链资本和主导产业。
- 时空演化：按上中下游与效应类型切换，展示六链聚合静态/动态关联矩阵与产出变化。
- 政策产业联动：展示政策工具结构、产业政策参考点、合作阶段政策工具、企业创新障碍和协同问题。
- 产业专题：按六条产业链切换，展示资本区域结构、核心产品、分链关联矩阵、产出口径和产业映射。
- 数据与方法：展示数据来源、抽取口径、页面表格映射和工程说明。

## 视觉风格

视觉语言参考开源 DataV 大屏风格：深色底、发光边框、矩阵热力、指标卡、联动筛选、数据态势网络。没有直接引入 `@jiaminghi/data-view` 或其他外部包，避免本地离线环境无法安装依赖。
